# Horoscope (राशिफल) service — initial brief

One final service for Nepali Archives: daily horoscope (राशिफल), "or something
like that" — scope deliberately loose until the literature review maps the
option space (दैनिक राशिफल, पञ्चाङ्ग/पात्रो elements, weekly/monthly, kundali…).

Process rule (established): literature review first — research, existing
products, algorithms, computation, content generation, licensing — then a
plan, then build. Constraints inherited from the archive: static site,
free forever, no ads/tracking, clean licenses, mission coherence.
