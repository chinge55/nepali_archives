# Stage 1 pipeline

Reproduce the gitignored `data/` and `build/` from scratch:

```bash
cd roman_nepali_transliteration

# Aksharantar Nepali (AI4Bharat; CC0 mined / CC-BY manual — attribute AI4Bharat)
curl -sL -o data/nep.zip \
  "https://huggingface.co/datasets/ai4bharat/Aksharantar/resolve/main/nep.zip"
(cd data && unzip -oq nep.zip)   # nep_train/valid/test.json (JSONL)
# nep_test.json (4,133 human-judged pairs) is HELD OUT for Stage 3 evaluation —
# build_lexicon.py must never read it.

# Leipzig Nepali news 2010 300K (CC-BY) — modern-register frequencies + bigram sentences
(cd data && curl -sL -O \
  "https://downloads.wortschatz-leipzig.de/corpora/nep_news_2010_300K.tar.gz" \
  && tar xzf nep_news_2010_300K.tar.gz)

# English pass-through wordlist (google-10000-english, filtered at build time)
curl -sL -o data/google-10000-english-no-swears.txt \
  "https://raw.githubusercontent.com/first20hours/google-10000-english/master/google-10000-english-no-swears.txt"

# Build (archive corpus is read in-place from ../archives/authors/*/*/text.txt)
python3 pipeline/test_normalize.py         # the keying contract must pass first
python3 pipeline/build_lexicon.py --install  # -> build/* AND vendors lexicons into ../assets/type/
node poc/test_engine.mjs                   # engine tests against the vendored assets
```

The engine itself (`assets/type/engine.js`, `app.js`, `rules.json`,
`autocorrect.json`) is hand-authored and tracked; `/type/` is generated by
`pipeline/build_site.py write_type_page`.

Files:
- `translit_keys.py` — `key_romanize()` / `normalize()` / `word_keys()`: the
  lookup-key contract shared by build and engine (JS port must stay in sync).
- `test_normalize.py` — the spec for that contract (variant sets + meet pairs).
- `build_lexicon.py` — filters Aksharantar noise by *agreement* (attested
  romanization vs ours under normalize), blends archive+news frequencies
  (archive ×2 in log space — register decision revisited in Stage 3), emits
  the two lexicon shards + bigram table + spot-check report.
- `../poc/rules.json` — hand-authored token table (tracked); costs encode the
  corpus priors from reviews/05.
